## Pemulihan Cepat (bangun ulang seluruh topologi Soal 1-10)

> Node Docker di GNS3 kehilangan isinya setelah dimatikan lalu dinyalakan lagi. Ikuti urutan di bawah dari atas ke bawah, dan paste **satu blok sekali**. Pastikan prompt konsol sesuai nama node sebelum paste.

Urutan wajib: rootkit → prab → tedd → alpha, beta, gamma, delta, epsilon, abbey, penny → obladi, desmond → oblada, molly.

### A. rootkit

IP internal:
```bash
cat > /root/rootkit-ip.sh << 'EOF'
for i in 1 2 3 4 5; do ip addr flush dev eth$i; done
ip addr add 10.90.2.1/24 dev eth1
ip addr add 10.90.4.1/24 dev eth2
ip addr add 10.90.3.1/24 dev eth3
ip addr add 10.90.1.1/24 dev eth4
ip addr add 10.90.5.1/24 dev eth5
for i in 1 2 3 4 5; do ip link set eth$i up; done
sysctl -w net.ipv4.ip_forward=1
EOF
```
NAT:
```bash
cat > /root/rootkit-nat.sh << 'EOF'
ip addr flush dev eth0
ip addr add 192.168.122.100/24 dev eth0
ip link set eth0 up
ip route replace default via 192.168.122.1
iptables -t nat -F POSTROUTING
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
EOF
```
Jalankan, set hostname, dan cek:
```bash
bash /root/rootkit-ip.sh
bash /root/rootkit-nat.sh
hostname rootkit; echo rootkit > /etc/hostname
echo -e "127.0.0.1 localhost\n10.90.2.1 rootkit.k53.com rootkit" > /etc/hosts
ip -br addr
ping -c 2 8.8.8.8
```
`eth1` sampai `eth5` harus punya subnet berbeda, dan ping ke internet harus berhasil.

**B6. Cek dan jalankan named**
```bash
named-checkconf
named-checkzone k53.com /etc/bind/k53/k53.com
named-checkzone 90.10.in-addr.arpa /etc/bind/k53/90.10.in-addr.arpa
pkill named; sleep 1; named
dig @127.0.0.1 +short vault.k53.com
dig @127.0.0.1 -x 10.90.3.2 +short
```
Kedua `named-checkzone` harus `OK`. `vault` harus menampilkan `10.90.2.4` dan `10.90.2.5`, dan `dig -x` harus menampilkan `penny.k53.com.`.

## 11. Konfigurasi Load Balancer (Penny & Abbey)

**Jalankan di Penny (Vault):**
```bash
apt-get update
apt-get install apache2 -y
a2enmod proxy proxy_http proxy_balancer lbmethod_byrequests headers

cat > /etc/apache2/sites-available/penny-proxy.conf << 'EOF'
<VirtualHost *:80>
ServerName www.k53.com
ProxyPreserveHost On
<Proxy balancer://vaultcluster>
BalancerMember http://10.90.2.4
BalancerMember http://10.90.2.5
ProxySet lbmethod=byrequests
</Proxy>
ProxyPass / balancer://vaultcluster/
ProxyPassReverse / balancer://vaultcluster/
RequestHeader set X-Real-IP "%{REMOTE_ADDR}s"
</VirtualHost>
EOF

a2ensite penny-proxy
a2dissite 000-default
apache2ctl configtest
service apache2 restart
```

**Jalankan di Abbey (Core):**
```bash
apt-get update
apt-get install nginx -y

cat > /etc/nginx/sites-available/abbey-proxy << 'EOF'
upstream core_cluster {
server 10.90.2.6;
server 10.90.2.7;
}
server {
listen 80;
server_name static.k53.com;
location / {
proxy_pass http://core_cluster;
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
}
}
EOF

ln -sf /etc/nginx/sites-available/abbey-proxy /etc/nginx/sites-enabled/abbey-proxy
rm -f /etc/nginx/sites-enabled/default
nginx -t
service nginx restart
```
*(Catatan: Jika ada error, ulangi restart di node Molly: `service php8.4-fpm restart` dan `service nginx restart`)*

**Uji Distribusi Beban di Alpha (Client):**

## 15. Pengecualian Path Proxy / Redirect (Penny & Abbey)

**Di Penny:**
```bash
mkdir -p /var/www/eternal
echo '<?php echo "Halo dari PHP Eternal di Penny!\n"; ?>' > /var/www/eternal/index.php
chown -R www-data:www-data /var/www/eternal

apt update && apt install -y libapache2-mod-php

service apache2 restart
echo '<?php echo "Halo dari PHP Eternal di Penny!\n"; ?>' > /var/www/eternal/index.php

```

Edit file `nano /etc/apache2/sites-available/penny-proxy.conf
`:
```apache
<VirtualHost *:80>
    ServerName www.k53.com
    ProxyPreserveHost On

    ProxyPass /eternal !

    Alias /eternal /var/www/eternal
    <Directory /var/www/eternal>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
    
    <Location /eternal>
        AddHandler application/x-httpd-php .php
    </Location>

    <Proxy balancer://vaultcluster>
        BalancerMember http://10.90.2.4
        BalancerMember http://10.90.2.5
        ProxySet lbmethod=byrequests
    </Proxy>

    ProxyPass / balancer://vaultcluster/
    ProxyPassReverse / balancer://vaultcluster/

    RequestHeader set X-Real-IP "%{REMOTE_ADDR}s"

    <Location /admin>
        AuthType Basic
        AuthName "Restricted Area"
        AuthUserFile /etc/apache2/.htpasswd
        Require valid-user
    </Location>
</VirtualHost>

```
```bash
apache2ctl configtest
service apache2 restart
```
Cek di client lain (Alpha)

**Di Abbey:**
